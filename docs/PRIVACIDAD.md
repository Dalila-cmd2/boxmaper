# Privacidad y datos — BoxMaper

BoxMaper es una herramienta de escritorio. **No hay servidor propio de BoxMaper** ni cuentas de usuario gestionadas por nosotros.

## Qué se guarda en tu equipo

- Proyectos (módulos, bornes, textos que introduzcas).
- Preferencias de sincronización (repositorio, intervalo, nombre de autor).
- Si configurás una clave de GitHub para publicar, se guarda en el **almacenamiento local** de la app (no se envía a terceros salvo a la API de GitHub cuando publicás o sincronizás).

## Qué se envía por Internet (solo si lo activás)

- **Actualizaciones de la app:** consulta a GitHub Releases (`latest.json` e instalador).
- **Datos centralizados:** lectura/escritura en el repositorio de GitHub que configures (por defecto `boxmaper-datos`).

Sin conexión, podés seguir editando proyectos guardados localmente y exportar PDF/Excel/CSV.

## Responsable del repositorio de datos

Quien publica en `boxmaper-datos` (o tu repo privado) decide qué información técnica de instalaciones se comparte con quien tenga acceso a ese repositorio.
